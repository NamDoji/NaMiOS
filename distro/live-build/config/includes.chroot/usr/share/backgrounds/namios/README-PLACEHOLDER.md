# NaMiOS wallpaper mặc định — PLACEHOLDER (chưa có asset thật)

Thư mục `usr/share/backgrounds/namios/` hiện **chưa có** file ảnh
wallpaper thật. Khi có asset thật (do NaMiOS tự thiết kế hoặc nguồn có
giấy phép phân phối lại rõ ràng — xem điều kiện trong
`usr/share/namios-branding/README-PLACEHOLDER.md`), đặt file tại đây
(ví dụ `namios-default.png` hoặc `.jpg`, khuyến nghị ≥ 1920x1080) và cấu
hình Plasma default theme trỏ tới file đó (phần cấu hình Plasma
look-and-feel thuộc công việc desktop/UI riêng, không phải file này).

KHÔNG dùng wallpaper có watermark/logo của bên thứ ba không có quyền
phân phối lại.
