Hướng dẫn nhanh cho người quen dùng Windows

Vừa chuyển từ Windows sang NaMiOS? Đây là những việc hay dùng nhất, chỉ mất vài phút để quen.

Nói thật: NaMiOS không phải Windows và không giả làm Windows. Nó sắp xếp thanh tác vụ và phím tắt gần giống để bạn đỡ bỡ ngỡ, nhưng tên vài ứng dụng sẽ khác. Phím tắt bên dưới đã cài sẵn; nếu máy bạn chưa chạy đúng, cứ dùng chuột qua menu Bắt đầu là xong.

Về Office: "Soạn thảo / Bảng tính / Trình chiếu" là LibreOffice — bộ văn phòng miễn phí thay thế Microsoft Office. Mở và lưu được file Word/Excel/PowerPoint thông thường, nhưng là phần mềm khác (file nhiều macro/định dạng rất cầu kỳ đôi khi hiển thị lệch chút).

1. "Máy này" (This PC) ở đâu?

  • Nhấn Windows + E để mở Trình quản lý tệp.
  • Cột bên trái: Tài liệu, Tải về, Màn hình nền, Thùng rác.
  • Mục Máy này liệt kê ổ cứng và USB đang cắm — bấm để mở.
  • Muốn gõ thẳng đường dẫn: bấm vào thanh địa chỉ phía trên rồi gõ/dán.
Rút USB an toàn: chuột phải vào tên USB ở cột trái → Rút an toàn, rồi mới rút ra để không mất dữ liệu.

2. Gõ tiếng Việt

  • Đã cài sẵn bộ gõ (Telex hoặc VNI, bạn chọn ở màn hình chào mừng).
  • Bật/tắt gõ tiếng Việt: nhấn Ctrl + Space.
  • Ô nhỏ gần đồng hồ (góc phải dưới) cho biết đang bật tiếng Việt hay không.
  • Gõ không ra dấu? Nhấn Ctrl + Space một lần để bật lại.
Mẹo: khi gõ mật khẩu mà ra chữ lạ, nhấn Ctrl + Space để tắt bộ gõ, xong bật lại.

3. Cài phần mềm

  • Mở Trung tâm phần mềm (giống Microsoft Store) từ menu Bắt đầu.
  • Gõ tên cần tìm (ví dụ "trình duyệt", "xem PDF"), bấm Cài đặt.
  • Máy có thể hỏi mật khẩu của bạn — đây là bước an toàn bình thường.
  • Gỡ phần mềm cũng ở đây: tìm ứng dụng → Gỡ cài đặt.
Cách an toàn để cài phần mềm là qua Trung tâm phần mềm, không tải file lạ trên mạng.

4. Tìm tệp hoặc ứng dụng

  • Tìm ứng dụng: nhấn phím Windows rồi gõ tên (gõ "bang tinh" không dấu cũng ra).
  • Tìm tệp: trong Trình quản lý tệp, bấm nút Tìm (kính lúp) rồi gõ tên tệp.
  • Mở tệp/thư mục bằng nháy đúp như Windows.

5. Mở file Word / Excel / PDF

  • Dễ nhất: vào Trình quản lý tệp, nháy đúp vào file — máy tự mở đúng ứng dụng.
  • Tạo mới: menu Bắt đầu → gõ "soạn thảo" (văn bản) hoặc "bảng tính" (bảng).
  • Khi Lưu, chọn định dạng .docx / .xlsx để người dùng Windows mở được.
Mở nhầm ứng dụng? Chuột phải vào file → Mở bằng → chọn đúng ứng dụng → tick "Luôn dùng cho loại tệp này".

6. Chụp màn hình

  • Nhấn phím Print Screen (trên bàn phím ghi là PrtSc).
  • Chọn chụp cả màn hình, một cửa sổ hoặc một vùng.
  • Bấm Lưu (vào thư mục Ảnh) hoặc Sao chép để dán (Ctrl+V).

7. Tắt máy / Khóa màn hình

  • Tắt máy: menu Bắt đầu → biểu tượng nguồn ⏻ → Tắt máy (có cả Khởi động lại, Đăng xuất).
  • Khóa nhanh khi rời máy: nhấn Windows + L.

8. Chuyển dữ liệu cũ từ Windows

  • Màn hình chào mừng có bước "Chuyển dữ liệu từ Windows": cắm ổ/USB, chọn thư mục, NaMiOS sao chép Tài liệu / Màn hình nền / Tải về / Hình ảnh sang.
  • Bỏ lỡ cũng được: mở Trình quản lý tệp, vào ổ cũ rồi tự chép sau.
An toàn: bước này chỉ sao chép, không xóa/di chuyển gì ở ổ Windows gốc — dữ liệu cũ vẫn còn nguyên.
Ghi chú trung thực: các phím tắt và cách mở ứng dụng ở trên là cấu hình đã đóng gói, chưa bấm thử trên mọi máy thật. Nếu máy/VM của bạn có mục lệch, báo lại để đội NaMiOS cập nhật. Tài liệu không hứa "giống Windows 100%".
